# DSH 工作台布局

[English](README.md) | 中文

一个独立的 DeepSeek Harness Web 插件，在不替换官方 AppFrame 和会话组件的前提下，将页面组织成工作区工作台：左侧导航、中间文件与终端区、右侧原生对话。

## 功能

- 左栏顶部通过紧凑的“会话 / 文件 / Git / 终端”控件切换；收起态严格采用 DSH 官方的圆形点击区与纵向节奏，展开态继续使用紧凑文字标签。“会话”使用 DSH 官方的列表气泡图标，与官方“新建会话”图形明确区分，并会恢复原生工作区与会话列表。展开态不再重复显示“新会话”长按钮；收起态只在“会话”模式保留原生新建会话行为，同时在浏览器绘制前同步状态并统一为正圆。其他模式仅将该原生按钮压缩并隐藏而不移出渲染树，因此切回会话时不会重新播放侧栏收起专用的横向入场动画。
- 收起栏的中段区域随模式切换：文件模式只提供新建文件和新建文件夹，Git 模式只提供更改/提交图切换，刷新、同步等仓库操作留在展开面板，终端模式提供新建终端及已有终端选择。收起态选中项沿用 DSH 的 active 表面色与信息蓝；文件树和新建入口使用明确的圆角折角文件图形，文件夹及叠加加号直接复用 DSH 官方图标。需要输入的创建操作会先展开左栏，再通过一次性命令交给文件面板，避免重复执行。
- 文件目录按需展开，不会一次读取整棵目录树；标题行展示 DSH 官方工作区的真实项目路径，长路径保持单行省略且可通过原生悬浮提示查看完整值。顶部使用成对的“文件 + / 文件夹 +”线框图标提供新建入口，采用紧凑的无外圈加号。名称输入框直接出现在所选目录中。选中文件时以其父目录为目标，新文件创建后会立即作为中栏标签打开。右键文件、文件夹、目录空白处，或使用键盘上下文菜单键，可打开 DSH 原生菜单：文件支持打开、重命名、删除及复制相对/绝对路径；文件夹另外支持在其中新建项目和展开/折叠；空白处提供根目录新建与刷新。
- 中栏使用 38px 紧凑顶栏和统一编辑器标签：普通文件、工作区 Diff、暂存 Diff 与提交 Diff 可以像 VS Code 一样同时打开、切换和关闭；文件较多时，在标签栏上滚动鼠标滚轮即可左右浏览，到达边界后会恢复页面正常滚动。每个文件标签独立保留草稿、未保存状态、Markdown 模式和保存错误，切换标签不会丢失修改。中栏不显示常驻保存按钮，只通过 `Ctrl/Cmd + S` 保存当前普通文件标签，并保留版本冲突保护与原子保存。左栏底部使用独立的两列工具行：官方“设置”按内容宽度显示，中栏图标开关独立靠右，不覆盖设置入口；开关状态变化会重置悬浮提示。收起和展开时，插件使用已注册的长度轨道让中栏与聊天栏按 DSH 官方 0.3 秒缓动连续插值，结束时仅在原子交还列位的一帧禁用原生过渡，避免产生反向二次动画；点击任意文件、Diff、终端或已有终端标签时会自动重新展开。
- 文件、编辑器选择、草稿、Diff 与 Git 状态绑定到 DSH 官方工作区 id；在同一工作区的不同会话之间切换会保留工作台，只有切换工作区才会切换整套状态。没有当前会话、会话尚未产生消息或会话暂未归属工作区时，工作台使用 DSH 官方最近工作区，因此仍可浏览文件与 Git。
- Markdown 文件首次打开默认显示 DSH 官方 Markdown 渲染结果，可在“预览 / 源码”之间切换；源码与 Markdown 界面始终限制在 AppFrame 的弹性中栏内，不会按内容反向撑宽布局。
- 中右栏优先使用 DSH AppFrame 原生列宽和拖拽处理；官方 AppFrame 在空会话 Hero 中主动隐藏详情轨道时，插件按同一套 300–520px 约束、360px 默认值、640px 中栏让步规则和无装饰拖拽热区补足轨道。临时网格会实时跟随官方左栏的 56px 收起控制栏、展开宽度和拖拽更新，首条消息产生后立即交还官方处理。
- Git 左栏工具栏使用独立的双轨提交图图标直接切换“更改 / 提交图”，不再与三节点源码管理图标混淆；旁边的“文件排列方式”菜单只负责列表与目录树。更改视图区分“已暂存”和“工作区”；提交图中展开的提交文件也支持同样的两种排列方式，两边的选择分别保留、互不影响。
- 提交图读取所有本地和远程分支，按拓扑顺序绘制分段着色的提交节点、分叉、汇合与 Merge commit；普通提交、引用边界和合并点分别使用实心点、空心环和双层环。每行只按当前经过的轨道动态留出图形宽度，避免单轨提交浪费左栏空间；提交信息保持紧凑单行，按“提交说明、作者、分支/远程/标签标志”排列。悬浮显示短提交号、时间以及真实的文件数和增删行统计，点击整行后在原位置展开该提交的文件。右键提交行或使用带无障碍名称的省略号菜单，可复制完整提交号、从该提交创建分支、Cherry-pick、Revert，或与当前工作区比较；比较结果仍按单文件 Diff 标签打开。
- 点击工作区、暂存区或提交图中的文件时，中栏把该文件的差异作为普通编辑器标签打开；同一 Diff 只保留一个标签，不同文件和不同版本可以同时打开，不会把整次提交的所有文件拼在一起。提交信息保留在 Diff 主工具栏中，不再另外占一行显示版本提交号。
- 仓库工具栏支持查看和切换本地/远程分支；可以从当前提交或指定引用创建分支、重命名当前分支，以及安全删除已合并的非当前本地分支。同时显示上游分支的拉取/推送计数，可管理带独立抓取/推送地址的命名远端，并同时提供便捷的上游操作和明确指定远端、分支的 Fetch、快进 Pull 与 Push。
- 中栏使用 CodeMirror MergeView 渲染只读 Diff，默认左右对照，包含行号、红绿变更块、未修改区域折叠和增删统计；可手动切换行内模式，窄列下会自动采用行内模式。普通文件与 Diff 两侧都默认对长行自动换行。
- 通过 xterm.js 与宿主 PTY 提供真正可交互的工作区终端。多个终端与文件共用中栏标签，切到其他文件时仍保持进程、ANSI 颜色和交互按键，尺寸会随中栏变化，启动目录固定为所选工作区根目录。中栏显隐过渡期间会冻结 xterm 当前网格，不再逐帧重排内容；收起状态绝不会按裁切后仍含内边距的窄盒子适配，只有重新展开并取得稳定可用宽度后才统一适配一次。关闭终端标签、切换工作区、连接断开或插件停止都会终止对应 PTY。
- 支持按文件或一次性暂存/取消暂存全部更改，并通过显式操作提交；提交后提交图会立即刷新。工作区更改可按文件或整批放弃，操作前使用 DSH 官方风险确认，且不会动已暂存内容。
- 分支切换、提交和远程操作完成后会在 Git 工具栏下方显示紧凑的中性反馈条，使用 DSH 官方提示表面与高对比文字，不再使用高饱和绿色底色。
- 右栏继续使用 DSH 原生聊天、输入框、任务状态与交互流程；DSH 将文件工具路径或本轮生成文件渲染为可点击控件后，插件会把路径安全解析到当前工作区，并作为普通文件标签在中栏打开，不再交给操作系统，普通 Markdown 链接和代码不受影响。工作台展开时，插件从官方 `conversation` 插槽包装层内标记实际的原生会话根节点，并使其与左栏使用同一套官方主题表面色，官方输入卡片及其全部子节点仍不受覆盖。收起中栏会同时释放列重排和主题覆盖，使聊天恢复官方中栏位置与原始颜色。窄栏下错误码会移到完整宽度的错误正文下方；助手消息按钮后的时间、用时、首 token 和速率统计按每条消息的真实渲染宽度检测，仅在发生溢出时移到按钮下方的完整宽度行并自然换行，不再被列边界裁切。输入工具栏仍保持单行，仅收紧间距、隐藏推理等级文字和权限/模型选择器内的下拉箭头，并省略过长模型名。箭头隐藏后，权限和模型按钮使用相同的左右内边距，模型选择器按内容宽度收缩，不再吞掉工具栏剩余空间。官方 Session-log 胶囊按钮只在此窄栏宽度下收成单个带无障碍名称的下载图标。官方模型菜单打开时仍由原 React 组件持有，但使用视口浮层坐标，避免被中栏裁切。
- 布局、文字、边框、按钮、图标、Markdown 和明暗主题尽量复用 DSH 官方组件与设计变量；Git 模块入口和分支选择器统一使用三节点源码管理图形。

## 安装

```sh
dsh plugin --profile web add @lsq64737/dsh-workbench-layout
```

卸载：

```sh
dsh plugin --profile web remove @lsq64737/dsh-workbench-layout
```

## 安全约束

- 浏览器只能提交 DSH 官方工作区 id 和工作区相对路径；宿主端通过 DSH 工作区注册表解析该 id，不信任浏览器路径，也不再从会话反推工作区身份。
- 路径越界、路径遍历和符号链接会被拒绝；文件编辑器只读取文本，Git Diff 对二进制文件仅显示类型提示，不传输原始字节。
- 保存使用 DSH 文件系统的版本令牌和 `workspace-write` 策略；新文件使用原子的 `createIfAbsent` 写入，同名项目不会被覆盖。新文件夹只在已验证的工作区父目录下创建一层，不会递归补建未知路径。
- 重命名与删除会先在已注册工作区内验证现有来源和目标，再调用宿主文件操作。重命名不会主动覆盖已发现的同名项目；工作区根目录和 Git 元数据受到保护。递归删除文件夹必须通过 DSH 风险确认，受影响的已打开文件存在未保存内容时会阻止重命名或删除。
- 只有用户明确选择“复制绝对路径”时，宿主才会返回绝对路径；普通目录请求仍只收发工作区相对路径，操作日志也只记录相对路径而非宿主路径。
- Git 使用固定参数直接调用可执行文件，不通过 shell；提交只会由明确点击“提交”触发。Cherry-pick 与 Revert 要求 Git 工作区干净、执行前显示确认，发生冲突时会自动中止对应操作。放弃更改仅作用于工作区，要求确认并保留暂存区，同时明确提示未跟踪内容会被删除。
- 分支和远程操作只由显式按钮触发，并禁用终端凭据提示；删除分支使用 Git 的已合并安全检查，删除远端要求勾选确认，Pull/Sync 使用快进模式，失败时不会自动合并、暂存或覆盖更改。
- Git 功能要求所选工作区就是仓库根目录，避免提交工作区之外已暂存的内容。
- API 复用 DSH 的可信主机、同源与跨站请求校验语义，只接受 JSON POST，并限制文件、目录与 Git 输出大小。
- 终端升级复用同一套 DSH 兼容的 Host、Origin 与跨站请求校验；浏览器只能选择官方工作区 id 和终端尺寸，不能指定进程路径、Shell 可执行文件、启动命令或工作目录。输入帧和终端数量均有限制，输出拥塞时会暂停 PTY，不会无上限积压内存。
- 终端意味着可以操作运行 DSH 的那台机器。任何能够访问受信任 DSH Web 来源的人都能使用该 Shell，因此只应在你信任的网络和主机上开放 Web 服务。

## 已知限制

- 文件和文件夹删除为永久操作，插件内没有回收站或撤销，因此文件夹删除必须显式勾选确认。
- 文件树会在打开文件时跟随高亮；点击树内空白区域会取消具体条目选择，并将后续新建操作的目标恢复为当前工作区根目录，不会关闭中栏标签。
- 符号链接不会在文件树中打开。
- 已打开标签及其草稿只保留在当前页面内，刷新页面会丢失未保存内容。
- 二进制文件由 Git 标记为二进制差异，不展示二进制内容。
- 提交图当前显示最近 40 条，不包含分页加载；未加载父提交的轨道会在底部保持延续，不会被错误画成终点。
- 远程操作依赖系统中已经配置好的 Git 凭据；插件不收集或保存远程账号、密码和令牌。
- 终端进程只在当前页面生命周期内存活；刷新、断线、切换工作区或关闭标签都会结束进程。默认组合最多允许八个终端连接同时存在。
- DSH 尚未提供公开的“移动原生聊天栏”接口，因此插件使用官方 AppFrame 的稳定标记调整列顺序。若未来官方重构页面骨架，布局选择器可能需要同步适配。
- 窄窗口触发 DSH AppFrame 官方让步规则时，会暂时收起文件编辑列并将对话恢复到中栏；窗口变宽后自动恢复三栏。

## 代码结构

- `src/index.ts`：宿主路由注册和请求分发。
- `src/workspace-backend.ts`：受控的目录、读取、原子保存、创建、重命名、删除、显式复制路径与会话文件索引解析。
- `src/git-backend.ts`：Git 状态、全部分支的拓扑提交、远端同步与配置、提交/工作区比较、单文件前后版本、暂存和显式提交操作。
- `src/client/controller.ts`：按工作区隔离的文件/Diff 统一标签、Git 主视图与文件排列、全局中栏可见状态、一次性收起栏命令、并发异步加载和草稿状态。
- `src/client/EditorTabs.tsx`：DSH 风格的可滚动文件与 Diff 标签、滚轮横移、边界放行、脏状态和关闭入口。
- `src/client/SourceControlIcon.tsx`：符合 DSH 尺寸与颜色约定的源码管理入口图标。
- `src/client/CreateEntryIcons.tsx`、`CommitGraphIcon.tsx`：新建文件/文件夹与提交图的 DSH 规格线框图标。
- `src/client/WorkbenchRail.tsx`：按文件、Git、终端模式提供官方 rail 几何的收起栏快捷操作。
- `src/client/workspace-binding.ts`：优先按 DSH 官方成员关系解析会话所属工作区，并在无会话状态下回退到官方最近工作区。
- `src/client/workspace-layout.ts`：工作区与 AppFrame 原生详情列状态绑定。
- `src/client/sidebar-top-layout.ts`：顶部模式切换的稳定 Portal 宿主、官方 Tooltip 相邻节点兼容与展开态新会话呈现适配。
- `src/client/sidebar-footer-layout.ts`：不移动 React 节点的官方设置/扩展操作插槽标记与独立底部工具行。
- `src/client/editor-layout-contract.ts`、`editor-track-transition.ts`：中栏显隐与终端共用的稳定 DOM 契约，以及采用 AppFrame 官方时长、缓动和原子交还机制的长度轨道协调。
- `src/terminal-protocol.ts`、`terminal-backend.ts`、`terminal-websocket.ts`：有界终端协议、工作区根目录 PTY 生命周期与可信 WebSocket 桥接。
- `src/client/fallback-details-layout.ts`：可跟随显隐状态、且在空会话 Hero 下与官方几何约束一致的临时详情轨道。
- `src/client/FileTree.tsx`、`FileTreeLevel.tsx`、`FileTreeCreateRow.tsx`：按需文件树编排、递归目录行与行内创建。
- `src/client/FileTreeContextMenu.tsx`、`FileTreeDialogs.tsx`、`use-file-tree-mutations.ts`：原生右键操作、确认界面与脏文件安全的重命名/删除状态。
- `src/client/clipboard.ts`：文件路径与提交号共用的剪贴板工具。
- `src/client/GitPanel.tsx`：源码管理状态编排。
- `src/client/GitChangesView.tsx`、`GitCommitFilesView.tsx`、`git-tree.ts`：更改与提交文件各自的列表/目录树呈现，以及共用的路径树构建规则。
- `src/client/GitGraphView.tsx`、`GitReferenceBadge.tsx`、`git-graph.ts`：提交图渲染、分段色轨道、引用标志、分叉/汇合连线和行内提交详情。
- `src/client/GitRepositoryToolbar.tsx`：独立主视图切换、文件排列、分支选择与远程操作入口。
- `src/client/GitBranchDialog.tsx`：复用 DSH 原生控件的分支创建、来源创建、重命名和安全删除弹窗。
- `src/client/GitRemoteDialog.tsx`：远端配置、指定远端/分支操作及破坏性确认弹窗。
- `src/client/GitCommitActionDialog.tsx`：提交图 Cherry-pick 与 Revert 的确认弹窗。
- `src/client/WorkbenchEditor.tsx`：中栏统一标签容器、源码编辑和 Markdown 预览。
- `src/client/TerminalPanel.tsx`、`TerminalSurface.tsx`、`TerminalIcon.tsx`：终端实例列表、xterm.js 中栏标签和 DSH 风格终端入口图标。
- `src/client/GitDiffEditor.tsx`、`DiffSurface.tsx`、`git-diff-labels.ts`：标签内单文件 Diff 工具栏、自适应布局、统一类型标签、自动换行和 CodeMirror 差异渲染。
- `src/client/layout-styles.ts`：官方 AppFrame 列顺序与原生分隔线视觉适配。
- `src/client/conversation-layout.ts`：右侧原生会话窄栏状态、按内容检测的助手统计换行、响应式 Session-log 操作标记与防裁切模型菜单几何。
- `src/client/conversation-file-routing.ts`：精确接管 DSH 生成文件索引并路由到工作区标签。
